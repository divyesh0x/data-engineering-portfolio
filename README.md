# Data Engineering Portfolio — 90-Day Build Sprint

**Goal:** Land a junior data engineering role. 90-day portfolio sprint, ~4 hrs/week.
**Started:** September 23, 2026

## Project 1 — Dataset
Canadian housing prices, Ottawa-focused (StatCan New Housing Price Index — Ottawa-Gatineau CMA, with Toronto, Vancouver, and Calgary as comparators)

## Business questions this project will answer
- How has Ottawa's price trajectory differed from Toronto and Vancouver since 2020?
- Which Ottawa segments (condo vs. single-family) drove the city's growth?
- Did Ottawa cool faster or slower than the other cities when rates rose?
